# 拾光集 · 生日与回忆小站

一份奶油粉色的生日礼物：手账卡片、飘落花瓣、回忆时间线、拍立得相册、便签墙，以及可以拆开的生日信。已适配手机和电脑。

[在线打开拾光集](https://leiye302.github.io/shiguang-birthday/)

## 预览

直接用浏览器打开 `index.html` 即可。也可以在安装 Node.js 18+ 的电脑上运行：

```sh
npm start
```

然后访问 <http://127.0.0.1:4173>。无需安装依赖，没有构建步骤。若端口已被占用，可设置 `PORT` 后运行。

## 换成我们的内容

所有可替换的文字、日期和素材路径都在 `content.js`：

| 字段 | 用途 |
| --- | --- |
| `siteTitle` | 网站名称，默认“拾光集” |
| `recipient` / `sender` | 对她的称呼、信件落款 |
| `birthday` | 本次庆祝日期 `2026-10-16`，与出生日期分开；提示按北京时间自动更新 |
| `birthDate` | 出生日期 `2006-10-16`，本次生日显示为 20 岁 |
| `anniversary` | 相恋日期 `2022-10-02`，起始日计为第 1 天 |
| `memories` | 回忆时间线的日期、故事、照片和标签 |
| `photos` | 相册图片、标题、描述 |
| `notes` | 便签与共同心愿 |
| `letter` | 生日信标题、正文段落 |
| `musicSrc` | 音乐文件路径；默认使用本机合成的轻柔音符 |

把照片放在 `assets/photos/`，再替换 `image` 字段，例如 `./assets/photos/our-first-trip.jpg`。首页两张相纸的图片与配文在 `index.html` 中。

现已填入称呼“康老师”、相恋日期和生日，并使用本人提供的六张照片：东北旅行、海南海滩、1000 天、初次约会、日出、晴天。图片按原文件复制；相册和时间线完整展示照片，首页相纸通过布局取景，原文件保持不变。旅行和初次约会的具体日期尚未提供，因此使用事件名称，没有推测日期。

便签、生日信正文和落款仍是可继续打磨的草稿；回忆配文依据已提供的照片与事件拟写。

## 现有交互

- 导航滚动与当前章节提示；移动端完整展示五个入口。
- 相册点击放大、上一张/下一张、键盘左右方向键翻页、Esc 关闭。
- 心愿勾选保存在当前浏览器的本地存储中；不跨设备同步。浏览器禁止存储时会提示。
- 生日信弹窗与许愿纸屑效果；弹窗使用浏览器原生焦点管理。
- 点击才播放音乐，离开标签页时暂停；没有自动播放。
- 尊重系统“减少动态效果”设置；无外部字体、图片、统计和音频请求。

## 发布

当前使用公开仓库与 GitHub Pages，发布来源为 `codex/birthday-scaffold` 分支的根目录。将修改推送到该分支后，GitHub 会自动重新部署，通常需要稍等片刻。

整个目录就是可部署的静态网站；保留相对路径也可以迁移到其他静态托管服务。

照片和文字发布后是否能被公开访问，取决于托管方式；本项目不含登录或访问控制。需要私密分享时，可以后续接入真正的访问保护。
